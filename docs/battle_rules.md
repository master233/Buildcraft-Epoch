# 战斗规则

## 0. 属性计算规则

所有战斗属性均按以下公式随等级成长：

```
属性值 = init_xxx + (等级 - 1) × lv_xxx
```

| 属性 | 初始值字段 | 每级成长字段 | 说明 |
|------|-----------|-------------|------|
| 生命值 | init_hp | lv_hp | 单位最大 HP |
| 攻击力 | init_atk | lv_atk | 决定伤害上限 |
| 防御力 | init_def | lv_def | 抵消攻击力 |
| 速度 | init_speed | lv_speed | 值越高越先行动 |
| 暴击率 | init_crit | lv_crit | 万分比（500 = 5%），触发时伤害 ×2 |
| 闪避率 | init_dodge | lv_dodge | 万分比（300 = 3%），触发时完全规避本次伤害 |

> 以上字段均配置在 `asserts/table/role_attrs.txt` 中。

## 1. 回合制出手顺序

- 战斗采用回合制，每轮所有存活单位各行动一次。
- 出手顺序由属性 **出手速度（speed）** 决定，speed 越高越先行动。
- speed 相同时，玩家方单位优先于怪物方；同方内顺序按 roles.txt 中的排列顺序。

## 2. 攻击目标选取

- 每个单位行动时，从**敌对方存活单位**中**随机选取**一个作为攻击目标。

## 3. 伤害计算

```
伤害 = max(攻击者.攻击力 - 受击者.防御力, 0)
```

- 若攻击力 ≤ 防御力，本次攻击造成 **0 伤害**（不回血、不穿透）。

## 4. 死亡判定

- 单位 HP ≤ 0 时立即死亡，播放死亡动画。
- 死亡单位**不能**再被选为攻击目标。
- 一方全部单位死亡时战斗结束：玩家方全灭为失败，怪物方全灭为胜利。
